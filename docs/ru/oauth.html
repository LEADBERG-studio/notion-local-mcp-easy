OAuth пошагово для новичка

Эта страница отвечает на вопрос: “что от меня требуется, где что менять и что копировать”.

Главная идея: сначала сервер должен иметь стабильный публичный HTTPS URL. Потом OAuth-клиент должен знать redirect URI и endpoints вашего MCP-сервера.

Вариант A: OAuth через встроенный setup

  1. Запустите OAUTH_SETUP.bat
    Выберите auth mode: oauth или dual. Если вы переходите со старого Bearer token и не хотите сломать старое подключение — выберите dual.
  2. Сохраните или перевыпустите owner code
    Owner code нужен, чтобы подтвердить владение локальным сервером при OAuth consent/registration flow. Не публикуйте его.
  3. Запустите START.bat
    Дождитесь public URL. Для OAuth лучше стабильный URL: Tunnellio domain, Serveo stable, sish или reverse proxy.
  4. Откройте SHOW_CONNECTION.bat
    Скопируйте public MCP URL, issuer/discovery endpoints и owner code, если клиент его запрашивает.
  5. В MCP-клиенте выберите OAuth-подключение
    Если клиент умеет discovery-first, укажите public base URL или MCP URL. Если просит endpoints вручную — используйте список ниже.

Endpoints, если клиент просит вручную

Пусть ваш публичный адрес:

https://mcp.example.com

Тогда:

MCP endpoint:                         https://mcp.example.com/mcp
Authorization server discovery:       https://mcp.example.com/.well-known/oauth-authorization-server
Protected resource discovery:         https://mcp.example.com/.well-known/oauth-protected-resource
Authorize endpoint:                   https://mcp.example.com/oauth/authorize
Token endpoint:                       https://mcp.example.com/oauth/token
Introspection endpoint:               https://mcp.example.com/oauth/introspect

Вариант B: заранее зарегистрировать OAuth client

Если клиент не умеет dynamic client registration или вы хотите BYO OAuth app:

  1. Запустите REGISTER_OAUTH_CLIENT.bat.
  2. Введите имя клиента, redirect URI, scopes и тип клиента.
  3. Для public client используйте PKCE, client_secret не нужен.
  4. Для confidential client сохраните и client_id, и client_secret.
  5. Вставьте эти значения в UI вашего MCP-клиента.

Redirect URI — самое частое место ошибки

Не придумывайте redirect URI. Его показывает MCP-клиент. Скопируйте ровно тот URI, который показывает UI клиента, включая путь, порт, slash и регистр.

Если OAuth не работает

  • Проверьте, что auth_mode = oauth или dual.
  • Проверьте, что public URL начинается с https://, если это не локальный тест.
  • Проверьте, что redirect URI в регистрации совпадает с URI клиента byte-for-byte.
  • Проверьте, что owner code не старый, если вы его перевыпускали.
  • Откройте SHOW_CONNECTION.bat и сравните endpoints.

Tunnellio server-side OAuth

Помимо OAuth Local MCP Easy существует отдельный OAuth-контур Tunnellio. Он настраивается в кабинете https://console.tunnellio.ru и описан в API-документации https://api.tunnellio.ru/docs. Не смешивайте его с bearer token Local MCP Easy. Подробнее — в разделе Tunnellio OAuth.
