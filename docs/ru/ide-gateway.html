Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

IDE Gateway — мост между IDE и моделью

ide_gateway — это плагин, который поднимает OpenAI-compatible шлюз для IDE. По умолчанию используется sandbox: модель одной командой запускает сервер в своей песочнице и keyless TCP bridge Tunnellio. Без SSH-ключей и без ручной возни.

Зачем это нужно: инструменты MCP менее надёжны, чем у IDE. Этот плагин позволяет работать в привычном IDE, но с моделью, которая видит ваши файлы и может вызывать MCP-инструменты. Общение IDE ↔ модель идёт напрямую, без сообщений в чате.

Как это работает

IDE (Cursor, Continue, VS Code, ...)
  → https://<hostname>.tunnellio.site/v1
  → keyless Tunnellio TCP bridge (--run --watch)
  → sandbox_server.py в песочнице модели
  → внутренний LLM endpoint/key этой же песочницы
  → ответ возвращается в IDE
Разделение: старый poll/queue режим вынесен в отдельный IDE Bridge (ide_bridge) со своим портом 8797 и ключом ideb_.... Здесь описан только sandbox TCP bridge.
Главная идея: команда «подними мост» запускает sandbox_bootstrap.py. Он сохраняет внутренние endpoint/key песочницы в state, поднимает сервер daemon-процессом и запускает Tunnellio bridge в watch-режиме. MCP tool-call может закончиться, а сервер и туннель продолжают жить.

Что остаётся постоянным

  • API key для IDE — локальный ideg_..., хранится в plugin config и обычно не меняется при обновлениях.
  • Base URL — после первого bootstrap берётся из Tunnellio и показывается через ide_gateway_show_config.
  • Эфемерный hostname — сохраняется в endpoint state и переиспользуется, пока живёт домен (обычно сутки). Если домен истёк, bootstrap создаст новый и сохранит его.
  • Кастомный hostname — если выбран в setup, используется постоянно.

Быстрый старт

  1. Запустите рабочую область в trusted developer mode.
    Через SETUP.bat в корне MCP включите trusted mode.
  2. Включите плагин.
    Откройте plugins\ide_gateway и запустите SETUP.bat. Выберите current, full_access, режим sandbox. Для начала берите ephemeral domain.
  3. Перезапустите MCP.
    STOP.bat → START.bat. Локальный endpoint поднимется, а public URL появится после bootstrap.
  4. Получите prompt.
    Вызовите ide_gateway_bridge_prompt. В sandbox-режиме он содержит одну bootstrap-команду.
  5. Скажите модели: «подними мост».
    Модель выполняет bootstrap, ждёт JSON и возвращает base_url.
  6. Скопируйте настройки в IDE.
    Вызовите ide_gateway_show_config с include_secret=true и возьмите base_url, api_key, model.
  7. Работайте.
    IDE обращается к public URL, запросы идут в песочницу модели напрямую.

Поддерживаемые эндпоинты

  • /v1/chat/completions (stream + non-stream)
  • /v1/responses (stream + non-stream, background, cancel, input_items)
  • /v1/completions (legacy)
  • /v1/models
  • /v1/tools + forced tool_choice
  • /v1/files (upload, list, get, content, delete)
  • /v1/images/generations, /v1/images/edits
  • /v1/audio/speech, /v1/audio/transcriptions, /v1/audio/translations
  • /v1/embeddings (local fallback)
  • /v1/moderations (local heuristic)

Жизненный цикл sandbox-моста

  1. ide_gateway_start создаёт endpoint state и сохраняет локальный IDE token.
  2. ide_gateway_bridge_prompt отдаёт одну команду для sandbox_bootstrap.py.
  3. Bootstrap читает внутренние endpoint/key песочницы из env и пишет их в state.
  4. sandbox_server.py стартует daemon-процессом и отвечает на OpenAI-compatible API.
  5. sandbox_tunnel.py запускает tunnellio bridge --run --watch, получает public URL и сохраняет hostname.
  6. При следующем запуске hostname переиспользуется. Если эфемерный домен истёк, будет создан новый.
Важно: в sandbox-режиме не нужен long-poll цикл. Если вам нужен старый совместимый путь, выберите режим bridge: там модель крутит bridge_step.py poll короткими вызовами, чтобы не ловить timeout MCP-tool-call.

Диагностика

  • ide_gateway_status — статус endpoint + счётчики очереди (pending/claimed/completed/failed/expired).
  • ide_gateway_show_config — готовые настройки для IDE.
  • ide_gateway_get_logs — последние записи (секреты замаскированы).
  • Endpoint state и очереди живут в gitignored temp/ide_gateway_runtime/.
