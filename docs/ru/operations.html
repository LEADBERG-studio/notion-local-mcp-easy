Ежедневный сценарий

  1. Запустите START.bat.
    Выберите папку из списка. Если у папки уже есть профиль подключения, больше вопросов не будет.
  2. Нужна новая папка?
    Пункт 0 в том же списке. Новая папка наследует текущий канал подключения, поэтому повторно настраивать протокол не нужно.
  3. Не закрывайте окно.
    Пока оно открыто, туннель и MCP доступны.

Если что-то срывается

Начните с инструмента transport_health. Он отвечает на главный вопрос: это ошибка инструмента или транспорт сбрасывает нагрузку.

  • rejectedOverload больше нуля — сервер намеренно отказывал в приёме. Уменьшите параллелизм или поднимите MCP_MAX_INFLIGHT.
  • replayedRetries высокий — клиент переотправляет запросы, которые уже дошли. Транспорт их распознаёт и не выполняет дважды.
  • cacheHits растёт — повторные чтения отдаются из памяти, до диска они не доходят.

Затем DOCTOR.bat: если окно launcher когда-то закрыли принудительно, его дочерний процесс мог остаться жив и держать порт на relay.

Логи

  • %LOCALAPPDATA%\NotionMcpEasy\server.log
  • %LOCALAPPDATA%\NotionMcpEasy\tunnel.log

Смотреть удобнее инструментом tail_file: интересное в логе почти всегда в конце.

Набор проверок при своей доработке

python -m py_compile server.py launcher.py core.py profiles.py plugin_runtime.py
python -m unittest discover -s tests -v
git diff --check
Если правите код: прогоняйте тесты не только на своей машине. Часть проверок зависит от платформы, и падение на Linux при зелёной Windows это типичный сюрприз. В проекте это уже случалось из-за регистра путей.

Безопасность

  • Не включайте trusted developer mode без необходимости.
  • Не коммитьте токены и секреты в git.
  • Не публикуйте прямые ссылки без auth.
  • Для OAuth используйте стабильный HTTPS public URL.
  • Для Git-правок используйте repo context и подтверждайте публикацию изменений.
  • Пароли баз данных задавайте через переменные окружения, а не в конфиге плагина.
