Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Эксплуатация и обслуживание

Запуск и остановка

  • START.bat / ./start.sh — запуск.
  • STOP.bat / ./stop.sh — остановка.
  • SHOW_CONNECTION.bat / ./show_connection.sh — показать параметры подключения.

Логи

  • %LOCALAPPDATA%\NotionMcpEasy\server.log
  • %LOCALAPPDATA%\NotionMcpEasy\tunnel.log

Перед релизом или важным изменением

python -m py_compile server.py launcher.py core.py profiles.py plugin_runtime.py
python -m unittest discover -s tests -v
git diff --check

Безопасность

  • Не включайте trusted developer mode для неизвестных клиентов.
  • Не храните токены и secrets в git.
  • Не открывайте сервер наружу без auth.
  • Для OAuth используйте HTTPS public URL.
  • Для Git-команд используйте repo context и подтверждайте изменения привязки.
