Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Ошибки и диагностика

Клиент не подключается

  • Проверьте, что окно START.bat открыто.
  • Проверьте URL через SHOW_CONNECTION.bat.
  • URL MCP должен заканчиваться на /mcp.
  • Проверьте auth mode: Bearer требует legacy или dual, OAuth требует oauth или dual.

OAuth ошибка redirect_uri

Redirect URI должен совпадать с тем, что показывает клиент. Нельзя менять slash, порт, path или схему.

OAuth требует HTTPS

Для внешнего OAuth используйте стабильный https:// URL. Исключение — локальная отладка на 127.0.0.1.

GitHub не даёт push workflow

Для файлов .github/workflows/*.yml credential должен иметь permission/scope workflow. Classic PAT: repo + workflow. Fine-grained PAT: Contents: Read and write + Workflows: Read and write.

Туннель не поднялся

  • Tunnellio: проверьте наличие tunnellio.exe и runtime config.
  • Serveo: проверьте SSH/key/hostname.
  • sish: проверьте DNS wildcard, relay host, SSH key и port.
  • reverse proxy: проверьте HTTPS certificate и proxy_pass на 127.0.0.1:8765.

Плагины не появились

  • Проверьте manifest plugins/<name>/plugin.json.
  • Проверьте secrets/env variables.
  • Перезапустите сервер.
  • Смотрите server.log.
