Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Workflow profiles

Workflow profile — это сохранённая рабочая область с режимом доступа, metadata и plugin state.

Зачем это нужно

  • Быстро переключаться между проектами.
  • Иметь разные plugin-настройки для разных workspace.
  • Не пересоздавать token при смене папки.

connections.cfg

MENU = on
PATH[1] = E:\project-a
PATH[2] = E:\project-b

Если MENU = on, при старте launcher показывает меню сохранённых путей.

workflow-profiles.json

Файл хранится в:

%LOCALAPPDATA%\NotionMcpEasy\workflow-profiles.json

Обычно его не надо редактировать вручную. Он содержит activeProfileId, список profiles, globalPlugins и plugin state.

Access mode

  • file_only — безопасный режим без запуска команд.
  • trusted — включает allow-listed command execution.
