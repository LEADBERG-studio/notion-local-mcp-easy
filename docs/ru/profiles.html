Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Профили

В продукте два разных вида профилей. Их легко перепутать, поэтому разберём отдельно.

ВидПро чтоЧем настраивается
Профиль подключенияКак сервер выходит наружу: Serveo, Tunnellio, sish, свой proxyPROFILES.bat
Рабочая областьКакая папка, какой режим доступа, какой профиль подключения используетсяSETUP.bat

Профили подключения (2.4.0)

Каждому виду подключения соответствует свой независимый контур кода со своими настройками и своими правилами. Контур не видит поля чужих контуров, поэтому он не может потребовать ключ от другого режима или преобразовать домен по чужим правилам.

Неизменяемый прообраз

У каждого профиля есть прообраз в connections/defaults/<id>.json. Он едет в релизе, руками не правится и содержит все значения по умолчанию. При первой настройке профиль клонируется из прообраза, поэтому вас спрашивают только то, что действительно нужно именно этому контуру.

Посмотреть прообраз можно прямо из меню: пункт b<номер>. Вернуть профиль к прообразу: r<номер>.

Что спрашивает каждый профиль

ПрофильВопросы
Serveo stable domainЗарезервированное имя и приватный SSH-ключ
Serveo temporary domainНичего
Tunnellio stable domainЗарезервированный домен и приватный SSH-ключ

Меню PROFILES.bat

<n>    настроить профиль n
v<n>   проверить профиль n
b<n>   показать неизменяемый прообраз профиля n
r<n>   сбросить профиль n к прообразу
q      выход

Есть и неинтерактивный режим:

python profiles_setup.py --list
python profiles_setup.py --configure tunnellio_random
python profiles_setup.py --verify serveo_stable
python profiles_setup.py --reset sish

Обновление продукта

Настроенные профили хранятся в %LOCALAPPDATA%\NotionMcpEasy\connection-profiles.v2.json и переживают обновление продукта. Они меняются только когда вы сами запустили PROFILES.bat.

Рабочие области

Постоянная запись обо всех рабочих областях и о том, какая из них активна, лежит в одном файле:

%LOCALAPPDATA%\NotionMcpEasy\current-connection.json

Для каждой области хранятся папка, режим доступа, выбранный профиль подключения, порт и учётные данные. Вручную этот файл править не нужно.

Токены

По умолчанию у каждой области свой MCP-токен и свой OAuth owner code, так что разные проекты изолированы. В SETUP.bat есть отдельный вопрос про общие учётные данные: включите его, если хотите переключать каналы подключения, не переподключая MCP-клиентов заново.

Access mode

  • file_only — безопасный режим без запуска команд.
  • trusted — включает allow-listed command execution.

connections.cfg

MENU = on
PATH[1] = E:\project-a
PATH[2] = E:\project-b

Файл сохранён для обратной совместимости и по-прежнему правится вручную. Теперь это зеркало известных рабочих областей: источник истины — current-connection.json. При обновлении продукта этот файл больше не перезаписывается.

workflow-profiles.json

Legacy-хранилище прежних workflow profiles. Оно остаётся для совместимости со старыми установками и plugin state, но выбор подключения им больше не управляется.
