Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Быстрый старт

Этот путь подходит, если вы хотите быстро подключить MCP-сервер и пока не разбираетесь в OAuth.

  1. Распакуйте архив
    Положите папку проекта в место без кириллических/проблемных символов в пути, если возможно.
  2. Выберите профиль подключения
    Запустите PROFILES.bat и посмотрите список. Два профиля готовы сразу и ничего не спрашивают: Tunnellio direct TCP bridge и Serveo temporary domain. Для первого запуска берите любой из них.
  3. Настройте рабочую область
    Запустите SETUP.bat. Он спросит три вещи: папку, режим доступа и профиль подключения из готовых.
  4. Оставьте file-only режим
    Пока вам нужны только файлы, выбирайте file_only. Trusted developer mode включите позже, когда понадобится запуск команд.
  5. Запустите START.bat
    Он спросит только рабочую область, если их несколько. Никаких вопросов про туннели, ключи и домены при старте больше нет.
  6. Скопируйте параметры подключения
    Launcher покажет URL и токен либо OAuth endpoints. Также можно открыть SHOW_CONNECTION.bat.
  7. Добавьте Custom MCP в клиенте
    Для legacy/Bearer укажите URL https://.../mcp и Authorization=Bearer <token> (Bearer token). Для OAuth используйте OAuth flow клиента.
Нужен постоянный адрес? Сгенерируйте SSH-ключ и зарезервируйте имя в аккаунте Serveo или в кабинете Tunnellio, затем настройте профиль Serveo stable или Tunnellio stable в PROFILES.bat: скрипт спросит только ключ и имя. Либо возьмите Tunnellio random, там нужен только API-ключ.
Не закрывайте окно сервера. Пока окно запущено, туннель и MCP доступны. Если закрыли — запустите START.bat снова.

Если ваша цель: IDE через модель

Сначала завершите обычный запуск MCP, затем включите trusted developer mode и настройте plugins\ide_gateway\SETUP.bat. После перезапуска напишите модели «подними мост». Полная пошаговая инструкция и резервный промт: IDE Gateway.

Не выбирайте наугад: ide_gateway нужен для прямого TCP bridge в песочницу модели. ide_bridge является отдельным queue/poll fallback.

Если клиент требует OAuth

Не пытайтесь вручную угадывать OAuth endpoints. Идите в OAuth пошагово: там расписано, что запускать и что копировать.

Минимальная проверка

  • Открыли SHOW_CONNECTION.bat и видите public URL.
  • В клиенте URL заканчивается на /mcp.
  • Для Authorization=Bearer <token> (Bearer token) включён auth mode legacy или dual.
  • Для OAuth включён auth mode oauth или dual.
