Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Свой домен и reverse proxy

Этот режим нужен, если у вас есть сервер/домен и вы хотите сами проксировать HTTPS-трафик на локальный MCP.

В режиме custom_proxy launcher не поднимает Tunnellio/Serveo/sish. Он просто считает указанный public_url каноническим внешним адресом.

Что нужно поднять на сервере

  • DNS-запись для домена, например mcp.example.com.
  • HTTPS certificate.
  • Reverse proxy: nginx, reverse proxy, Traefik или аналог.
  • Маршрут на локальный сервер 127.0.0.1:8765 или на машину, где он доступен.

Что выбрать в setup

  1. Запустите SETUP.bat.
  2. Выберите Custom public URL / reverse proxy.
  3. Введите только base origin, например https://mcp.example.com.
  4. Не добавляйте /mcp, query string или trailing path.

Пример nginx

server {
    listen 443 ssl;
    server_name mcp.example.com;

    ssl_certificate     /path/fullchain.pem;
    ssl_certificate_key /path/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8765;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto https;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

Для OAuth

Используйте один и тот же origin для всего:

Public base URL: https://mcp.example.com
MCP endpoint:    https://mcp.example.com/mcp
Issuer:          https://mcp.example.com
