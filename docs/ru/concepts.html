Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Что это такое

Notion Local MCP Easy запускает MCP-сервер на вашем компьютере. MCP-клиент, например Notion Agent или другой агент, подключается к этому серверу и получает инструменты для работы с выбранной папкой.

Важно: это не публичный многопользовательский сервис. Это локальный инструмент для вашего компьютера и доверенного агента.

Из каких частей состоит система

Локальный сервер

Python/FastMCP сервер слушает 127.0.0.1:8765 и работает только с выбранным workspace.

Публичный URL

Нужен, если MCP-клиент находится не на той же машине. URL даёт Tunnellio, Serveo, sish или ваш reverse proxy.

Авторизация

legacy = Bearer token, oauth = OAuth 2.1, dual = оба способа одновременно.

Workspace

Папка, в которой агенту разрешено читать/писать файлы. Выход наружу блокируется.

Режимы доступа

РежимЧто умеетКогда использовать
file-onlyФайлы внутри workspaceПо умолчанию. Самый безопасный режим.
trusted developer modeДополнительно запускает разрешённые команды: Python, Git, Node, npm и т.п.Только для доверенного агента и доверенной папки.

Где хранятся настройки

  • %LOCALAPPDATA%\NotionMcpEasy\config.json — основная локальная конфигурация.
  • %LOCALAPPDATA%\NotionMcpEasy\runtime.json — текущий runtime/tunnel state.
  • %LOCALAPPDATA%\NotionMcpEasy\connection.txt — summary подключения.
  • %LOCALAPPDATA%\NotionMcpEasy\oauth_state.json — OAuth clients/tokens/state.
  • %LOCALAPPDATA%\NotionMcpEasy\workflow-profiles.json — workflow profiles и plugin state.
  • connections.cfg рядом с launcher.py — меню сохранённых workspace.
