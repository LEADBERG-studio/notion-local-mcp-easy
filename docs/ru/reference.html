Tunnellio API endpoints

Для интеграций Tunnellio предоставляет POST-only API: /v1/meta, /v1/capabilities, /v1/keys*, /v1/domains*, /v1/domains/connection-profile, /v1/launch-spec, /v1/sessions/open, /v1/sessions/heartbeat, /v1/sessions/resume, /v1/sessions/close, /v1/sessions/status. Авторизация API: Authorization: Bearer <Tunnellio API token>. Подробное объяснение - в Tunnellio.
