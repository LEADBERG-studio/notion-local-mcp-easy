Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Способы подключения

Есть два независимых выбора: как клиент авторизуется и как он добирается до локального сервера.

Новое в 2.4.0: подключения переработаны. У каждого вида подключения свой независимый контур со своими настройками и своими правилами. Профили настраиваются отдельным скриптом PROFILES.bat, сохраняются между обновлениями продукта и не мешают друг другу.

Три шага вместо одного мастера

СкриптЧто делаетЧто спрашивает

Семь протоколов, на которых строятся профили

Профиль подключения это именованный экземпляр протокола. Один протокол можно сохранить несколько раз с разными доменами и ключами, а выбор в списке делается номером 1-N.

ПрофильЧто вы готовите самиЧто спросит скрипт
Serveo stable domainSSH-ключ и зарезервированное имя в аккаунте ServeoКлюч и имя. Больше ничего
Serveo temporary domainНичегоНичего. Домен случайный
Tunnellio stable domainSSH-ключ и домен в кабинете TunnellioКлюч и домен. Больше для этого режима ничего не требуется
Tunnellio random domainAPI-ключ в кабинетеТолько API-ключ. Проверяется на сервере сразу при настройке
Tunnellio direct TCP bridgeНичегоНичего. Домен и API-ключ опциональны
Self-hosted sish relayСвой relay, wildcard DNS и SSH-ключХост, порт, домен, subdomain, ключ
Custom public URLСвой reverse proxyПубличный origin

Где что хранится

  • connections/defaults/<id>.json — неизменяемый прообраз профиля. Едет в релизе, руками не правится, содержит все значения по умолчанию.
  • %LOCALAPPDATA%\NotionMcpEasy\connection-profiles.v2.json — ваши настроенные профили. Обновление продукта их не трогает.
  • %LOCALAPPDATA%\NotionMcpEasy\current-connection.json — рабочие области и активный выбор.
  • %LOCALAPPDATA%\NotionMcpEasy\config.json — генерируемое зеркало активного профиля для обратной совместимости. Поля неактивных контуров в нём всегда пустые.
Никаких молчаливых переключений. Если активный канал не поднялся, launcher скажет об этом прямо и не станет сам уходить на другой. Смена канала — всегда явное действие через SETUP.bat.

Токены при смене канала

По умолчанию у каждой рабочей папки свой MCP-токен и свой OAuth owner code. Если вы хотите менять каналы подключения, не переподключая MCP-клиентов заново, включите в SETUP.bat общие учётные данные для всех областей.

Windows команды

  • START.bat — старт сервера и туннеля. Спрашивает только рабочую область.
  • PROFILES.bat — настроить профили подключения: настройка, проверка, просмотр прообраза, сброс к прообразу.
  • STOP.bat — остановить процессы этого MCP.
  • SETUP.bat — рабочая область: папка, режим доступа, профиль подключения.
  • SHOW_CONNECTION.bat — показать URL/token/auth mode/discovery endpoints.
  • OAUTH_SETUP.bat — настроить OAuth/dual/legacy.
  • REGISTER_OAUTH_CLIENT.bat — заранее зарегистрировать OAuth client.
  • BUILD_RELEASE.bat — собрать release archive.

POSIX команды

Сценарий: постоянный MCP URL через Tunnellio

Если нужен стабильный внешний адрес и управляемая авторизация, используйте Tunnellio: настройте подключение в https://console.tunnellio.ru, запустите tunnellio connect --run --watch --name notion-mcp, затем возьмите public URL через tunnellio show-config --name notion-mcp. Подробности — в разделе Tunnellio.
