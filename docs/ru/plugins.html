Главное правило

Не публикуйте токены, owner code, client secret и локальные config-файлы.

Плагины

Плагины расширяют MCP-сервер прикладными инструментами. В комплекте есть DB-family плагины, AI/subagent provider и ide_gateway — мост между IDE и моделью.

Главное правило: папка в plugins/ только делает плагин обнаруживаемым. Для обычного включения не редактируйте внутренние profile-файлы. Откройте папку нужного плагина и запустите SETUP.bat или ENABLE.bat.

Что уже есть в комплекте

ПлагинПапкаДля чего
SQLiteplugins\sqliteЛокальная SQLite DB внутри workspace.
PostgreSQLplugins\postgresПодключение к PostgreSQL через установленный psql.
OpenAI-compatible providerplugins\openai_compatAI provider или subagent через OpenAI-compatible chat completions API.
IDE Gatewayplugins\ide_gatewayПолный OpenAI-compatible мост между IDE и активной MCP-моделью (long-poll bridge).

Как включить плагин

  1. Запустите MCP хотя бы один раз через START.bat.
    Так launcher создаст активный workflow profile для выбранной рабочей области.
  2. Откройте папку нужного плагина.
    Например: plugins\ide_gateway, plugins\sqlite, plugins\postgres или plugins\openai_compat.
  3. Запустите SETUP.bat.
    Setup спросит, включать плагин для current рабочей области или global для всех областей.
  4. Ответьте на вопросы настройки.
    Для DB/AI plugins setup собирает connection/provider config. Для ide_gateway обычно достаточно дефолтов.
  5. Перезапустите MCP.
    Registry tools строится на старте, поэтому после enable/disable нужен restart.
  6. Проверьте диагностику.
    В агенте можно вызвать list_plugins или plugin_status, чтобы увидеть loaded/not_attached/effective mode.

Файлы в папке каждого плагина

ФайлЧто делает
SETUP.batИнтерактивно включает плагин: scope, mode, простой выбор default/custom, вопросы настройки, запись локального конфига.
ENABLE.batТо же включение через общий helper; удобно для повторной настройки.
DISABLE.batУдаляет локальный конфиг для выбранного scope.
STATUS.batПоказывает локальные конфиги плагина для global/current.
plugin.jsonManifest: id, tools, modes, entrypoint.

Где хранятся настройки

Setup создаёт локальный config рядом с плагином:

  • plugin.local.global.json — плагин включён глобально;
  • plugin.local.current.<profile-id>.json — плагин включён только для текущей рабочей области.

Эти файлы локальные, игнорируются Git/release archive и читаются plugin runtime при старте MCP.

SQLite plugin

Запустите plugins\sqlite\SETUP.bat. Setup спросит alias подключения и путь к SQLite-файлу относительно workspace.

Connection alias: main
SQLite file path relative to workspace: data\app.db

После restart появятся tools sqlite_list_connections, sqlite_list_tables, sqlite_describe_table, sqlite_query и, в full access, sqlite_execute.

PostgreSQL plugin

Запустите plugins\postgres\SETUP.bat. Setup спросит alias, database, host/port/user и имя environment variable для пароля. Сам пароль в plugin config не сохраняется.

Connection alias: main
Database name: app
Host: localhost
User: app_user
Password env var: APP_POSTGRES_PASSWORD

Перед запуском MCP задайте переменную окружения с паролем, если она нужна вашему подключению.

OpenAI-compatible plugin

Запустите plugins\openai_compat\SETUP.bat. Setup спросит provider alias, base URL, имя environment variable с API key и модели.

Provider alias: local
Base URL before /chat/completions: http://127.0.0.1:1234/v1
API key env var: LOCAL_AI_API_KEY
Default model: local-model

IDE Gateway plugin

Запустите plugins\ide_gateway\SETUP.bat. Обычно выбирайте current и full_access, а затем оставляйте defaults. Подробная инструкция: IDE Gateway.

Как выключить

  1. Откройте папку плагина.
  2. Запустите DISABLE.bat.
  3. Выберите current или global.
  4. Перезапустите MCP.
Важно: после любого enable/disable нужен restart MCP. Hot reload registry tools пока не реализован.
