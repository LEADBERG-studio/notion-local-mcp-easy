Плагины

Плагины расширяют MCP-сервер прикладными инструментами. В текущей версии уже есть foundation для DB-family и AI/subagent-family плагинов.

Главное правило: сам факт наличия папки в plugins/ только делает плагин обнаруживаемым. Плагин не подключается автоматически: его нужно явно прикрепить к current или global scope и перезапустить MCP, чтобы пересобрался registry tools.

Что уже есть в комплекте

IDE Provider: active bridge для IDE

ide_provider поднимает локальный OpenAI-compatible endpoint на 127.0.0.1. IDE отправляет запрос в /v1/chat/completions, активная MCP-модель забирает его через ide_provider_wait_request и возвращает ответ через ide_provider_send_response.

  • Нужен trusted developer mode для запуска и остановки endpoint.
  • Endpoint использует локальный token с префиксом idep_.
  • Runtime state, logs и queue лежат в ignored temp/ide_provider_runtime/.
  • Подробная инструкция: IDE Provider для новичков.

Global или current scope

ScopeЧто значитКогда использовать
globalПлагин доступен во всех workflow profiles, если его не переопределили в current profile.Общий AI provider или общая DB.
currentПлагин привязан к текущему workspace/profile.Проектная DB, проектный AI profile, локальный SQLite.

Effective mode

  • read_only — регистрируются только read-only tools.
  • full_access — регистрируются и mutating/subagent tools, но только если активный profile находится в trusted mode.
Важно: full_access невозможен вне trusted mode. Это сделано специально, чтобы плагин не мог обойти общий safety gate.

Где хранится plugin state

%LOCALAPPDATA%\NotionMcpEasy\workflow-profiles.json

Внутри файла есть два места:

  • globalPlugins — глобальные подключения;
  • profiles[activeProfileId].plugins — подключения текущей рабочей области.

Как подключить плагин: общий порядок

  1. Выберите текущий workspace
    Запустите START.bat и выберите нужный slot/path, если меню включено.
  2. Решите scope
    global — для всех workspace, current — только для текущего.
  3. Подготовьте секреты
    Пароли и API keys храните в environment variables. В config пишите только имя переменной, например APP_POSTGRES_PASSWORD или OPENAI_COMPAT_API_KEY.
  4. Добавьте attachment в profile storage
    Если UI/команда attach ещё недоступны в вашем flow, делайте это аккуратно через workflow-profiles.json.
  5. Перезапустите MCP
    Hot reload tools не реализован: после attach/detach нужен restart.
  6. Проверьте диагностику
    Смотрите server.log, healthcheck/diagnostic output и список tools в MCP-клиенте.

SQLite plugin: пример current attach

SQLite connection path должен оставаться внутри workspace.

{
        "profiles": {
          "ВАШ_ACTIVE_PROFILE_ID": {
            "plugins": {
              "SQLite": {
                "scope": "current",
                "requestedMode": "read_only",
                "config": {
                  "connections": [
                    {
                      "name": "main",
                      "path": "data/app.SQLite"
                    }
                  ]
                }
              }
            }
          }
        }
      }

SQLite full access

Для SQLite_execute нужен requestedMode: "full_access" и trusted profile. Используйте только если агенту реально можно менять базу.

PostgreSQL plugin: пример current attach

Плагин использует psql, поэтому psql должен быть доступен в PATH. Пароль передаётся через environment variable, указанную в password_env.

{
        "profiles": {
          "ВАШ_ACTIVE_PROFILE_ID": {
            "plugins": {
              "postgres": {
                "scope": "current",
                "requestedMode": "read_only",
                "config": {
                  "connections": [
                    {
                      "name": "main",
                      "host": "127.0.0.1",
                      "port": "5432",
                      "database": "app",
                      "user": "app_user",
                      "password_env": "APP_POSTGRES_PASSWORD",
                      "sslmode": "prefer"
                    }
                  ]
                }
              }
            }
          }
        }
      }
Не пишите реальный пароль PostgreSQL в workflow-profiles.json. Создайте переменную окружения APP_POSTGRES_PASSWORD и храните пароль там.

OpenAI-compatible plugin: пример global attach

Подходит для OpenAI API, локального OpenAI-compatible endpoint или любого совместимого chat-completions provider.

{
        "globalPlugins": {
          "openai_compat": {
            "scope": "global",
            "requestedMode": "read_only",
            "config": {
              "providers": [
                {
                  "name": "main",
                  "base_url": "https://api.tunnellio.ru/v1",
                  "api_key_env": "OPENAI_COMPAT_API_KEY",
                  "default_model": "gpt-4.1-mini",
                  "subagent_model": "gpt-4.1"
                }
              ],
              "default_provider": "main",
              "default_model": "gpt-4.1-mini",
              "subagent_defaults": {
                "temperature": 0.2,
                "max_output_tokens": 800
              }
            }
          }
        }
      }

Subagent mode

openai_compat_run_subagent требует full_access under trusted profile. Для обычной генерации текста достаточно openai_compat_generate_text в read_only.

Как узнать activeProfileId

  1. Откройте %LOCALAPPDATA%\NotionMcpEasy\workflow-profiles.json.
  2. Найдите поле activeProfileId.
  3. В секции profiles найдите объект с таким ключом.
  4. Добавляйте current plugins именно в этот объект.

Manifest плагина

Каждый plugin folder должен содержать plugin.json. Минимальные поля:

{
        "id": "my_plugin",
        "display_name": "My Plugin",
        "version": "1.0.0",
        "entrypoint": "plugin.py",
        "supported_modes": ["read_only", "full_access"],
        "capabilities": ["database"],
        "config_schema_version": 1,
        "required_env": [],
        "dependencies": [],
        "required": false,
        "install_scope_support": "both",
        "tools": []
      }

Как написать свой плагин

  1. Создайте папку plugins/my_plugin.
  2. Добавьте plugin.json с manifest и tool descriptors. Tool names должны начинаться с my_plugin_.
  3. Добавьте plugin.py.
  4. В plugin.py реализуйте validate_config(config, context), healthcheck(context) и invoke(tool_name, arguments, context).
  5. Не регистрируйте tools напрямую в обход общего registry.
  6. Добавьте тесты и прогоните стандартный gate.

SQLite plugin

SQLite-плагин предоставляет инструменты чтения локальных SQLite-баз, включая sqlite_query. Команда sqlite_execute относится к изменяющим операциям и требует режима full_access.
